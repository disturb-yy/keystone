# ADR 目录索引

本目录保存 Keystone 已接受、难以逆转且需要保留取舍背景的架构决策。ADR 解释“为什么这样定”，不替代 Ticket 实施规格、源码、测试或当前运行行为证据。

## 使用规则

- 仅记录修改成本高、脱离上下文容易被误解、且经过真实方案取舍的决策。
- 新 ADR 使用递增四位编号和简短文件名；已失效的决策通过后续 ADR 说明替代关系。
- 术语定义归入根 `CONTEXT.md`，可验证的当前路径和状态归入根 `INDEX.md`。
